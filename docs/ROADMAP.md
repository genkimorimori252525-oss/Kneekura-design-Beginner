# Roadmap — AI-first design research for personal projects

## v0.1 — Core reference index (implemented)

- Seed external sources with licences and provenance (six screenshot references + useful native libraries).
- Record UI genres, concrete technology targets, and exhaustive two-axis compatibility.
- Provide machine-readable use-case recommendations and local CLI validation.
- Keep the index lightweight and free of copied source/assets.

## v0.2 — Per-component assessment (only when needed)

- Record component-level compatibility, implementation/version caveats and time to integrate.
- Add verified screenshots/previews **only where the owner has rights**; otherwise link to the upstream example.
- Let agents record "adopt", "visual reference", "reject", or `NO_CHANGE_NEEDED` with evidence; avoid repeated trial-and-error.

## v0.3 — Optional personal experiment bench

- Sandbox self-written or authorized adaptations of selected patterns for the owner's projects.
- Test responsiveness, interaction, reduced motion, frame time, accessibility and regressions.
- Keep UI experiments project-scoped when integrating them into Minecraft, Android or JavaFX.

## Later — Better private AI search

- Optionally add local semantic search over summaries and compact source cards.
- Build design tokens/native adapters only if multiple active projects need them.
- Keep public visibility changes under owner control; ensure CI/tests can continue if moved private.

**Not goals:** publishing a UI kit, selling/design-distributing components, bulk mirroring libraries, chasing total source count, or overriding a working design solely for cosmetic improvements.
