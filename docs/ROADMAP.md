# Roadmap — AI-first hobby design research

## v0.1 — Source discovery [done]
20 external sources; licensing and source-origin notes; 14 genres; 8 technology targets; compatibility matrix; use-case map; simple JSON CLI.

## v0.2 — Design selection laboratory [implemented; validate in CI]
15 original, locally rendered concepts in 5 UI genres; component-level needs taxonomy (12); two-way browser preview/compare; AI-first, explicit choice/abstention receipts; evidence/rationale/technical-budget gates; no mandatory APIs.

## v0.3 — Grounded project verification [next]
For selected prototypes, add **real** consumer-project screenshots (only if authorized for the research repository), keyboard/mobile checks, measured frame/CPU/render metrics, and decision outcomes. Improve designs based on genuine test failures rather than chasing decorative changes.

## v0.4 — Optional agent visual inspection automation
When screenshot-enabled browser tooling is available, create read-only screenshot comparisons of **owned** prototypes and append traceable evidence. Do not pretend the CLI itself contains a multimodal model.

## v1.0 — Personal knowledge refinement
Collect what the AI chose and why, document rejected patterns, reconcile changed upstream licensing/version metadata, and build high-confidence design defaults for recurring project environments (Forge/JavaFX/Android/Web). Keep the repo privacy owner's choice.

**Excluded goals**: public UI product, bulk third-party mirroring, forced code rewrites, mandatory inference/API expense, confusing visual demos with deployable native UI.
